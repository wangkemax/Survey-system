## Part 1 · 现场物理条件

### 基础参数

| 维度 | 实测 | 评价 |
|---|---|---|
| 作业面积 | 4,387 ㎡ | 本次项目范围内真实面积（说明书写 8,121 ㎡，含其他业务线，不在范围） |
| 梁下净高 | 8.0 m | 优。可做 5–6 层货架 + Mezzanine 夹层 |
| 地面承重 | 5,000 kg/㎡ | 优。远超一般物流仓，支持重型货架 + 托盘 AGV |
| 主通道宽度 | ≥ 3.5 m | 满足 AGV/AMR 双向通行 |
| 月台高度 | 0 mm（平地式） | ⚠ 缺口。4 个卸货门均无高位月台，AGV 无法直接对接货车 |

### 物理约束清单（5 大分组）

**1. 空间与承重** — 净高 8m、承重 5000kg/㎡、主通道 3.5m，均满足自动化要求。

**2. 月台与装卸** — ⚠ 4 个门全为平地式（0mm），需加装液压登车桥（4 台约 32 万）。

**3. 网络与电气** — ⚠ 全仓无工业 WiFi；电气容量需为 AGV 群充电 + 工作站增容。

**4. 地面条件** — 平整度 6mm（临界值，AGV 容忍 ±8mm 勉强可用）；业主方**不允许自流平、不允许打孔**，方案须避开磁条导航，采用 SLAM 激光导航。

**5. 业主方改造许可** — 地面打孔 ✗ / 自流平 ✗ / 墙面附挂 待确认 / 电气增容 ✓ / 网络布线 ✓ / 退场需可逆。

### 环境

| 项 | 实测 | 标准 | 缺口 |
|---|---|---|---|
| 照度 | 150 lux | 拣货区建议 ≥ 300 lux | 偏低，需补光 |

## Part 2 · 订单与流程（口径已校验）

> ⚠ 口径教训：上午口头报"日均 1000 单"，与半月实际数据差近 30 倍。报数必问「单 / 行 / 件」。

### 真实订单数据（半月样本）

| 口径 | 半月合计 | 日均 | 备注 |
|---|---|---|---|
| 订单数 | 549 单 | 37 单 | — |
| 订单行 | 9,800 行 | 653 行 | 17.8 行/单 |
| 件数 | 27,545 件 | 1,836 件 | 2.8 件/行 |

### 业务结构

- **配送模式**：提前 3 天下单、当晚做次日单 → 本质是**次日波次拣选**，不是 4 小时级即时配送。（业主口述"JIT 60%"需还原为真实时窗。）
- **产线分化**（平均值掩盖结构，须按产线拆分）：
  - 1/2 号线：**不看批次**，可走标准货到人模式。
  - 3 号线：**所有 SKU 必须按指定批次出库 + 基本一单一件** → 错件代价极大（整单作废），同 SKU 不同批次须严格物理隔离。

### SKU 结构

| 项 | 值 |
|---|---|
| SKU 总数 | 6,800 种（项目范围内） |
| 小件占比 | 93% |
| 长尾特征 | 极重，约 4,600 SKU 流量低、价值密度低 |

## Part 3 · 系统现状（自研 WMS）

| 能力 | 现状 |
|---|---|
| 货位管理 | ✓ 支持 |
| 批次管理 | ✓ 支持 |
| CID（构型/件号）管理 | ✗ 缺 |
| 工位级配送 | ✗ 缺 |
| RFID 追溯 | ✗ 缺 |
| 多客户/多产线 | ✗ 缺 |
| 拣选路径优化 | ✗ 缺 |
| 设备群调度 | ✗ 缺 |

> 自研 WMS 仅支持「货位 + 批次」，缺 CID / 工位 / RFID 等 **7 项**关键能力。

### 与客户 MES 对接现状

- 业主称"与 MES 有 API 实时接口"，**实际只共享『订单』一类数据**；库存 / 发货 / 批次 / CID / 工位 / 质量均未接通。
- 性质：客户**内部系统对接**（非跨公司），扩展难度低但工作量不小。
- 教训：问"API 通"不够，要问「**具体共享哪几类数据**」。

## 自动洞察（基于填写数据自动生成）

1. **配送时窗 = 次日波次** → 核心 KPI 是「次日单按时齐套率」，不是即时响应速度。
2. **3 号线一单一件 + 强批次** → 必须物理隔离 + AMR 专车 + 双重扫码 + AI 视觉批次识别（B 区拆 B1/B2）。
3. **拣货走动占比高（拆零为主，17.8 行/单）** → 货到人 AMR 价值突出，是 ROI 最高环节。
4. **WMS 缺 ≥ 3 项关键功能（实缺 7 项）** → WMS 需升级或替换，且必须建 MES 多数据类直连。
5. **租赁/通用仓 + 业主禁打孔禁自流平** → 优先 SLAM 激光 AGV + 螺栓装配货架 + 软件层（100% 可迁移），改造层最小化、可逆。
6. **月台 0mm + 无 WiFi + 照度偏低** → 隐藏成本：登车桥、工业 WiFi、补光须计入预算。
