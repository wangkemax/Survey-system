## 方案要点速览

- **五区混合方案**：A 大件托盘 / B1 普通拣选 / B2 批次锁定 / C 长尾 / D 长形件
- **总投资** ≈ 1,165 万（软件 300 + 设备 810 + 改造 55）
- **回收期** ≈ 3 年，综合残值率 ≈ 50%
- **明确拒绝** 全 ASRS（投资 2500-3500 万、残值 ≤30%）和 Shuttle 驶入式

- 半月订单：549 单 / 9800 行 / 27545 件
