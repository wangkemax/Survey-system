# Survey System · 仓库自动化诊断调研工具包

> 把一次性的项目调研工具，固化成团队可复用的标准化产品。
> 让任何一个团队成员都能像资深顾问一样，30 分钟完成现场调研、5 分钟产出诊断报告。

---

## 这是什么

一套用于**仓库自动化升级项目**的现场调研工具包，起源于仓库自动化升级项目。

核心思路：**经验沉淀 → 标准化交付 → 规模化复制**

- 📋 行前准备清单（Checklist）
- 📱 移动端现场调研工具（单文件 HTML，手机即用）
- 📄 自动生成 Markdown / 可视化方案文档
- 📚 项目案例库（持续沉淀经验）

## 为什么做

| 痛点 | 解决 |
|---|---|
| 调研靠老顾问个人经验，新人接不住 | 工具内置评分维度 + 自动洞察，标准化 |
| 现场记录零散，回来整理耗时 | 边调研边录入，一键导出报告 |
| 每个项目从零开始，经验不沉淀 | 案例库 + 经验教训库持续积累 |
| 给客户的材料不够专业 | 自动生成可视化方案文档 |

## 工具组成

| 工具 | 用途 | 形态 |
|---|---|---|
| `tools/site_survey.html` | 现场物理条件 + 自动化机会评分 | 移动端 HTML |
| `tools/deep_survey.html` | 系统 / 订单 / 流程深度调研 | 移动端 HTML |
| `tools/layout_solution.html` | 方案可视化文档（布局图 + 投资估算） | 桌面 HTML |
| `templates/checklist.xlsx` | 行前准备 + 现场核对清单 | Excel |

## 快速开始

1. 用手机浏览器打开 `tools/site_survey.html`
2. 现场边走边填（数据自动保存在本地浏览器）
3. 调研完点「导出 Markdown 报告」
4. 把报告交给方案组，或导入 `layout_solution.html` 生成方案
