# 调研工具操作手册 · USER GUIDE

> 面向：第一次用三件套去现场的同事。
> 目标：看完这份，你不靠老顾问陪同也能独立完成一次现场调研 + 出报告。
> 配套：行前清单 [`templates/checklist.xlsx`](../templates/checklist.xlsx) · 范例案例 [`cases/liugong/`](../cases/liugong/)

---

## 0. 三件套是什么、什么时候用哪个

| 工具 | 解决的问题 | 什么时候用 | 形态 |
|---|---|---|---|
| `tools/site_survey.html` | 现场物理条件 + 自动化机会评分 | 到现场第一件事，边走边填 | 手机 |
| `tools/deep_survey.html` | 订单 / 系统 / 流程深度调研 | 坐下来访谈、要数据时 | 手机/平板 |
| `tools/layout_solution.html` | 把调研结论变成可视化方案文档 | 回公司做方案时 | 电脑 |

一句话流程：**site_survey 看"仓库行不行" → deep_survey 看"业务是什么" → layout_solution 出"方案长什么样"**。

## 1. 行前准备（出发前一天）

1. 打开 [`templates/checklist.xlsx`](../templates/checklist.xlsx)，逐项确认「行前准备」页。
2. 手机浏览器先打开 `site_survey.html` 和 `deep_survey.html` 各一次，确认能正常加载（首次加载后离线也能用）。
3. 提前向客户要：**半月或一个月的订单明细**（含单号/行/件，最好带产线维度）、仓库平面图、现有系统清单。
4. 关键一问先发给客户对一下口径：「这次项目范围内的**真实面积和 SKU** 是多少？」（避免被文档总数带偏，见经验 5）

> ⚠ 数据存在手机浏览器本地（localStorage）。**不要中途清缓存、不要换浏览器**，否则数据丢失。调研完立刻导出。

## 2. 现场调研流程（建议 ≤ 4 小时）

### 第 1 步 · 物理巡场（site_survey.html，约 1 小时）

边走边填，重点别漏这 5 组物理约束：

1. **空间与承重** — 净高、地面承重、主通道宽度。
2. **月台与装卸** — 月台高度（0mm 要记！没有就得加登车桥）。
3. **网络与电气** — 有没有工业 WiFi、电气能否增容。
4. **地面条件** — 平整度、能否打孔/自流平。
5. **业主方改造许可** — 打孔 / 自流平 / 墙面附挂 / 退场处置，逐项问清（见经验 8）。

7 个维度逐一打分，工具会自动给「选型提示」。物理条件填完先别走，看一眼自动提示对不对。

### 第 2 步 · 业务访谈（deep_survey.html，约 2 小时）

三个 Tab 依次过：

- **订单流程**：录入订单数据。**每个数字都要问清是「单 / 行 / 件」**（见经验 2），并追问**下单到送达的时窗**（见经验 1）。
- **系统现状**：照「数据拉取清单」逐项核对 WMS/MES 能力，重点问 MES「**具体共享哪几类数据**」（见经验 10）。
- **异常访谈**：用三角色访谈卡（主管/拣货员/IT）收集金句，记录"最怕什么""最耗时什么"。

> 滑块填百分比、严重度打分，工具会按规则自动生成"洞察段"。

### 第 3 步 · 收尾导出

1. 各工具点「**导出 Markdown 报告**」。
2. 把导出的内容存为 `cases/{客户}/01_调研报告.md`。
3. 现场没把握的数字，标 `—` 占位，别瞎填。

---

## 3. 回公司：出方案

1. 人工提炼 `02_关键发现.md`——把数据背后的判断写出来（参考样板范例，每条 = 现象 + 判断 + 对方案的影响）。
2. 打开 `tools/layout_solution.html`，按调研结论填分区、设备、投资估算，生成 `03_方案文档.html`。
3. 投资估算细化到 `04_投资明细.xlsx`（软件/设备/改造三层 + 残值率，参考样板范例）。
4. 项目结束，必写 `05_经验教训.md`——这是案例库最有价值的部分。

## 4. 标准案例目录结构

每个项目在 `cases/` 下建一个客户目录，固定五件套：

```
cases/{客户}/
├── 01_调研报告.md      # 工具导出 + 校对
├── 02_关键发现.md      # 人工提炼洞察
├── 03_方案文档.html    # 可视化方案
├── 04_投资明细.xlsx    # 投资估算
└── 05_经验教训.md      # ★ 最重要
```

照着 [`cases/liugong/`](../cases/liugong/) 抄结构最快。

## 5. 常见问题（FAQ）

**Q：微信里打开工具，点重置/导出没反应？**
A：微信内置浏览器会拦截原生弹窗。工具已用自定义确认弹窗规避；若仍异常，改用系统浏览器（Safari/Chrome）打开。

**Q：手机填到一半切了别的 App，数据还在吗？**
A：在。数据实时存本地。但**别清缓存、别用无痕模式、别换浏览器**。

**Q：导出的报告在哪？**
A：点导出后内容会生成在页面/下载区，复制到 `01_调研报告.md` 即可。

**Q：底部按钮被手机刘海/底栏挡住？**
A：iOS 已留安全区；若仍被挡，旋转横屏或下滑页面。

**Q：客户报的订单量和实际差很多？**
A：99% 是口径问题（单/行/件混淆）。一定以**订单明细导出的数据**为准，不要用口头数字（见经验 2）。

**Q：物理条件某项现场没测到怎么办？**
A：标 `—`，回头补。报告里"凭印象"内容应 ≤ 20%。
